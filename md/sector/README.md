# 공통 탐사 규칙
- "슬롯"은 포켓몬 한 마리의 자리를 말한다. 1슬롯당 포켓몬 한 마리가 들어갈 수 있다.
    - 각 지역마다 1슬롯이 해방되어 있다.
    - 파견 보낼 수 있는 포켓몬은 최초 1마리, SECTOR 03 해금 후 300 RP로 최대 2마리의 포켓몬을 파견할 수 있고, SECTOR 05 해금 후 900 RP로 3마리의 포켓몬을 파견할 수 있게 된다.
- 동일 포켓몬은 다른 지역으로 중복 파견할 수 없다. 같은 유저가 같은 지역에 동시 파견할 수 없다(슬롯은 SECTOR당 1개이기 때문).
- 모든 파견은 독립적으로 계산한다(SECTOR 01의 6시간 탐사와 SECTOR 02의 15분 탐사는 종료 시간이 다름).

## 4. 이벤트 종류
구간마다 아래 중 하나가 일어난다. 기본 비중이며 지역·경로가 보정한다.
| 이벤트 | 기본 비중 | 내용 |
|------|------|------|
| 채집 | 55% | 위 등급 표로 소재 획득 |
| 위험 | 15% | 지역 위험 발생. HP 피해와 상태 이상 판정 |
| 조우 | 15% | 야생 포켓몬과 간이 자동 배틀. 승리 시 채집 1회 추가(고급 하한 10%), 패배 시 HP 피해 |
| 관측 | 10% | 해당 지역 관측 데이터 1개, 04 이후 지역에서 낮은 확률로 AD |
| 기믹 | 5% | 지역 고유 기믹 이벤트 |
